## 🎯 Пошаговая инструкция (простая версия)

### Шаг 1: Откройте Railway
- Перейдите на https://railway.app
- Войдите через GitHub

### Шаг 2: Создайте проект
1. Нажмите **"New Project"** (большая кнопка в центре)
2. Выберите **"Deploy from GitHub repo"**
3. Найдите **"ilyaknirim/domdom"**
4. Кликните на него

Railway начнет импорт.

### Шаг 3: Настройте Root Directory
1. **Кликните на блок сервиса** (прямоугольник на канвасе)
2. Откроется правая панель
3. Перейдите в **"Settings"**
4. Прокрутите до **"Root Directory"**
5. Введите: `backend`
6. Нажмите Enter

### Шаг 4: Добавьте PostgreSQL ⬅️ ВОТ ТУТ КНОПКА "+ New"

**ВАЖНО:** Закройте правую панель (нажмите ESC или кликните на пустом месте), чтобы вернуться на канвас!

1. **Посмотрите в ПРАВЫЙ ВЕРХНИЙ УГОЛ** 
2. Найдите фиолетовую кнопку **"+ New"**
3. Кликните на неё
4. В меню выберите **"Database"**
5. Выберите **"PostgreSQL"**

Появится новый блок PostgreSQL!

### Шаг 5: Добавьте Redis

1. Снова нажмите **"+ New"** (правый верхний угол)
2. Выберите **"Database"**
3. Выберите **"Redis"**

### Шаг 6: Добавьте переменные окружения

1. **Кликните на блок "Backend"**
2. Перейдите в **"Variables"**
3. Нажмите **"New Variable"** (внизу)

Добавьте эти переменные **ПО ОДНОЙ**:

```
NODE_ENV = production
PORT = 3000
TELEGRAM_BOT_TOKEN = ваш_токен_от_botfather
JWT_SECRET = any-long-random-string-minimum-32-characters
FRONTEND_URL = https://temporary.com
```

### Шаг 7: Подключите DATABASE_URL (важно!)

Это НЕ обычная переменная! Это **ссылка** на PostgreSQL.

1. Нажмите **"New Variable"**
2. В поле **Name** введите: `DATABASE_URL`
3. **Справа от поля Value** найдите маленькую кнопку **"$"** (иконка переменной)
4. **Кликните на неё** - поле Value превратится в выпадающий список
5. В списке выберите:
   - Сначала **"Postgres"** (сервис)
   - Затем **"DATABASE_URL"**

Должно получиться: `${{Postgres.DATABASE_URL}}`

### Шаг 8: Подключите REDIS_URL

Аналогично DATABASE_URL:

1. Нажмите **"New Variable"**
2. Name: `REDIS_URL`
3. Кликните на **"$"** справа от Value
4. Выберите:
   - **"Redis"**
   - **"REDIS_URL"**

Должно получиться: `${{Redis.REDIS_URL}}`

### Шаг 9: Создайте домен для Backend

1. Останьтесь в Backend сервисе
2. Перейдите в **"Settings"**
3. Прокрутите до **"Networking"**
4. Нажмите **"Generate Domain"**
5. Railway создаст URL: `https://что-то.up.railway.app`

**СКОПИРУЙТЕ И СОХРАНИТЕ ЭТОТ URL!**

### Шаг 10: Подождите деплоя

1. Перейдите в **"Deployments"**
2. Дождитесь зеленой галочки **"Success"**
3. Если красный крестик **"Failed"** - кликните на него и посмотрите логи

### Шаг 11: Проверьте работу

Откройте в браузере:
```
https://ваш-url.up.railway.app/health
```

Должен вернуть:
```json
{"status":"ok","timestamp":"..."}
```

## ❓ Часто задаваемые вопросы

### Q: Я не вижу кнопку "+ New"
**A:** Убедитесь что вы на канвасе (рабочей области), а не в настройках сервиса. Нажмите ESC или кликните на пустое место.

### Q: Как переключить поле Value на Reference ($)?
**A:** Справа от поля Value есть маленькая кнопка с иконкой "$" - нажмите на неё. Поле превратится в выпадающий список.

### Q: Деплой Failed - ошибка с Prisma
**A:** Это нормально при первом деплое. Railway пытается применить миграции. Подождите, он перезапустится автоматически.

### Q: Backend URL не отвечает (502/503)
**A:** Backend еще запускается. Подождите 2-3 минуты после деплоя.

### Q: Ошибка "tsc: not found"
**A:** Я уже исправил это! Просто убедитесь что вы используете последнюю версию кода с GitHub.
