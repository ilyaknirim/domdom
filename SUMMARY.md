## 🏗️ Архитектура

### Backend (Node.js + TypeScript)
```
Express.js → Middleware → Controllers → Services → Prisma → PostgreSQL
                ↓
          WebSocket (Socket.IO) для real-time
                ↓
              Redis для кэширования
```

### Frontend (React + TypeScript)
```
React Router → Pages → Components → API Service → Backend
                ↓
         Telegram Mini App SDK
                ↓
          React Query для кэширования
                ↓
            Tailwind CSS для стилей
```

### База данных (PostgreSQL)
```
9 таблиц:
  - User (пользователи)
  - Property (недвижимость)
  - Booking (бронирования)
  - Payment (платежи)
  - Review (отзывы)
  - Favorite (избранное)
  - Notification (уведомления)
  - Message (сообщения)
  - BlockedDate (заблокированные даты)

15+ индексов для производительности
20+ связей между таблицами
```

## 🚀 Следующие шаги

### Для запуска:

1. **Клонируйте проект**
2. **Создайте Telegram бота** (TELEGRAM_BOT_SETUP.md)
3. **Настройте .env файлы**
4. **Запустите `docker-compose up`**
5. **Откройте Mini App в Telegram**

Детальная инструкция → [QUICKSTART.md](./QUICKSTART.md)

### Для деплоя:

1. **Backend → Railway / Heroku**
2. **Frontend → Vercel / Netlify**
3. **База → Railway / Supabase**
4. **Настройте домен в BotFather**

Детальная инструкция → [DEPLOY.md](./DEPLOY.md)
